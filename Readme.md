# Cyber.Armourscope

Cyber Security main page. Vue 3 + Vite single-page app.

## Commands

```sh
npm install    # once
npm run dev    # dev server with hot reload
npm run build  # production build to dist/
npm run preview  # serve the production build locally
```

## Structure

- `src/views/HomeView.vue` — the home page (hero, Docs and Capabilities panels)
- `src/assets/css/` — neon-glow Bootstrap 4 theme + main.css
